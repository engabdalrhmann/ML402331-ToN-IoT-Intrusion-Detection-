# Dataset information

**Dataset:** ToN_IoT Network Dataset  
**Selected file:** Network_dataset_1.csv  
**Source:** https://research.unsw.edu.au/projects/toniot-datasets

The selected CSV was inspected locally and contains 1,000,000 records and 46 columns. The binary `label` distribution is:
- `0` (normal): 208,679 records
- `1` (attack): 791,321 records

The raw CSV is intentionally not committed to GitHub because it is approximately 140 MB. Download it from the official UNSW ToN_IoT source. Verify the exact file/version and label definitions against the dataset documentation before final modeling.
